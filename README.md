## 3. TA 활동일지

### 교육TA

교육TA 기준은 실습TA와 별도로 운영합니다.

- 참여율: 10% / 20% / 30%
- 석사 최소 활동시간: 15 / 30 / 44시간
- 박사 최소 활동시간: 15 / 30 / 45시간

처리 흐름:

학생 작성  
→ 학생 본인서명  
→ 교수서명 대기  
→ 교수 등록 이메일 인증  
→ 교수 담당 교육TA 내용 확인  
→ 선택 일괄서명  
→ 최종 PDF 생성  
→ 통합관리 자동 반영

교수 인증 이메일은 학교메일 또는 Gmail 여부를 구분하지 않습니다.

**사업단 통합관리의 교수 명단에 관리자가 등록한 이메일**을 인증 기준으로 사용합니다.

사업단 관리자는 필요한 경우 교수서명 대기 건을 위임서명할 수 있습니다.

최종 PDF에는 위임서명 여부, 내부 처리계정, 처리시각 등의 내부 관리정보를 표시하지 않습니다.

### 실습TA

- 참여율: 12% / 24% / 36%
- 최소 활동시간: 18 / 36 / 54시간

처리 흐름:

학생 작성  
→ 학생 본인서명  
→ 사업단 제출  
→ 사업단장 서명 또는 승인된 위임서명  
→ 최종 PDF 생성

실습TA에는 교수서명 단계가 없습니다.

## 4. 관리자 운영

통합관리에서는 다음 업무를 관리합니다.

- 전체 현황
- 신청·처리 관리
- 명단 관리
- 계정·권한
- TA 활동일지
- 자료·배포 관리
- 변경 이력

### 명단 관리 기준

- 양성학생: 학번 필수
- TA 대학원생: 학번 필수
- 교수: 사번 선택
- 직원: 사번 선택

교수·직원은 사번이 없는 경우 이메일을 기준으로 기존 명단과 매칭할 수 있습니다.

## 6. GitHub Pages 수정 시 주의사항

1. 기존 파일명을 임의로 변경하지 않습니다.
2. Apps Script 배포 URL은 반드시 현재 운영 중인 `/exec` 주소를 사용합니다.
3. 배포 ID와 웹앱 URL을 혼동하지 않습니다.
4. URL의 대문자 `I`, 소문자 `l`, 숫자 `1`을 주의합니다.
5. 수정 후 GitHub Pages 배포가 완료된 다음 브라우저에서 `Ctrl + F5`로 새로고침합니다.
6. 개인정보, 교수·학생 명단, 참여율, 지급금액 등 내부 데이터는 GitHub HTML에 직접 저장하지 않습니다.

## 7. Apps Script 운영 원칙

각 프로젝트는 역할별로 분리하여 운영합니다.

- 사업단 통합관리 접속화면
- 사업단 통합관리 자료서버
- 교육TA 자료서버
- 교육TA 웹작성·서명제출
- 실습TA 자료서버
- 실습TA 웹작성·서명제출

서로 다른 Apps Script 프로젝트의 코드를 임의로 합치지 않습니다.

기존 웹앱을 수정할 때는:

`배포 → 배포 관리 → 기존 웹앱 선택 → 수정 → 새 버전 → 배포`

방식으로 진행하여 기존 URL을 유지합니다.

**새 배포를 임의로 만들지 않습니다.**
