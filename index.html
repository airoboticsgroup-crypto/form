사업단 서식안내

본인에게 해당하는 메뉴에서 필요한 서식을 찾아 작성하세요.
서식별 제출기한과 별도 공지사항을 먼저 확인해 주세요.

작성 및 제출 안내

  1. 1서식 선택학생용·직원용·교수용에서 필요한 서식을 엽니다.
  2. 2사본에 작성구글시트는 ‘파일 → 사본 만들기’ 후 작성합니다. 원본에 직접 입력하지 않습니다.
  3. 3내용·서명 확인필수 항목을 작성하고 해당 서식에서 요구하는 본인·담당교원 서명을 받습니다.
  4. 4PDF 이메일 제출서명이 포함된 PDF와 필요한 증빙자료를 사업단 이메일로 제출합니다.

제출 이메일: ai.robot@kw.ac.kr　/　파일명: 성명_서식명_해당연월.pdf

구글폼은 폼에서 직접 작성·제출합니다. 전자결재·공동 작성 등 별도 안내가 있으면 해당 안내를 우선 적용합니다.

학생용 서식

링크가 없거나 열리지 않으면 사업단에 문의해 주세요.

메뉴 구분은 이용 안내이며, 파일 접근권한은 연결된 서비스에서 관리합니다.
