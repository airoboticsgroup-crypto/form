사업단 서식안내

학생용·교수용·직원용·공통서식에서 필요한 서식을 찾아 작성하세요.
서식별 제출방법과 업무 진행 순서를 확인해 주세요.

작성 및 제출 안내: 서식별 작성방법 다름

  1. 1. 구글폼 서식폼 작성·제출 → 사업단 접수
  2. 2. 활동일지사본 작성 → 확인·서명 → PDF 저장 → 이메일 제출 → 관리자 취합
  3. 3. 신청·결과보고서자동화 서식 작성 → 증빙 첨부·필요 시 서명 → 사업단 제출 → 관리자 취합·검토

서식별 별도 안내와 기존 전자결재가 있으면 해당 절차를 따르세요. 프로세스별 자세한 안내 ↓

학생용 서식

여러 역할이 함께 쓰는 서식은

프로세스별 안내

업무명을 누르면 담당자별 진행 순서를 볼 수 있습니다. 자동화 연동은 순차 적용하며, 현재 서식의 제출 안내를 우선 따르세요.

TA 추천과 활동일지
  1. 추천·신청 접수 · 교수·지정 신청자

    학생·교과목·담당교원·참여율·활동기간을 제출합니다. 필요한 추천·서명 자료를 함께 준비합니다.

    다음: 사업단 검토

  2. 검토·승인 · 직원

    추천 내용과 적용 기준을 확인하고 승인·보완·반려 상태를 기록합니다.

    다음: 승인 배정 확정

  3. 월간 활동일지 발급 · 직원

    승인 명단과 해당 학기 시간표를 바탕으로 학생·교과목·월별 작성본을 제공합니다.

    다음: 학생 작성

  4. 실제 활동 작성 · 학생

    예정 시간을 실제 활동에 맞게 고치고 근무내용을 작성합니다. 여러 시간은 13:00~15:00, 16:00~18:00처럼 입력합니다.

    다음: 교원 확인·서명

  5. 확인·PDF 제출 · 학생·교수

    학생·담당교원 확인 및 서명을 마친 PDF를 공지된 이메일로 제출합니다.

    다음: 사업단 수신 확인

  6. 검토·보완·마감 · 직원

    수신·시수·내용·서명과 적용 기준을 확인합니다. 보완본과 최종본을 구분해 보관합니다.

    다음: 마감 또는 보완 요청

교과목 계획과 결과
  1. 계획 제출 · 교수

    교과목·운영기간·참여기업·계획과 예산을 작성하고 필요한 서명을 받습니다.

    다음: 사업단 검토

  2. 검토·사업 등록 · 직원

    계획을 검토하고 승인된 사업번호와 기본 정보를 등록합니다. 변경 사항은 이력을 남깁니다.

    다음: 교과목 운영

  3. 결과보고 제출 · 교수

    실제 운영 결과와 최종 집행 내역을 작성하고 교안 등 필요한 자료를 첨부합니다.

    다음: 사업단 확인

  4. 결과 확인·보관 · 직원

    같은 사업번호로 계획과 결과를 연결하고 내용·첨부·서명·집행 내역을 확인합니다.

    다음: 마감 또는 보완 요청

비교과 계획과 결과
  1. 지원 신청 · 교수·지정 담당자

    프로그램 유형·명칭·일정·장소·내용·예산을 작성합니다.

    다음: 사업단 검토

  2. 검토·회차 등록 · 직원

    승인된 프로그램과 개최 회차를 구분해 등록합니다.

    다음: 프로그램 운영

  3. 결과보고 제출 · 교수·지정 담당자

    실제 일정·참가 명단·성과·최종 집행 내역을 작성하고 사진·홍보물 등 자료를 첨부합니다.

    다음: 사업단 확인

  4. 참가·결과 확인 · 직원

    회차별 인원과 기간 전체 중복 제거 인원을 구분하고 양성학생 여부와 증빙을 확인합니다.

    다음: 마감 또는 보완 요청

행사 신청과 결과
  1. 행사 신청 · 직원·해당 작성자

    행사명·일정·장소·내용·신청 예산을 작성합니다.

    다음: 검토·승인

  2. 개최·결과 작성 · 직원·해당 작성자

    승인된 행사번호로 실제 참석인원·행사 내용·사진·증빙을 연결합니다.

    다음: 결과 검토

  3. 검토·마감 · 직원

    신청과 실제 결과, 참석 명단과 집행 증빙을 대조하고 최종본을 보관합니다.

    다음: 마감 또는 보완 요청

재료구입
  1. 신청 작성 · 학생·교수 등 해당 신청자

    신청자·교과목 또는 사업을 선택하고 품목·규격·VAT 포함 금액과 견적서를 준비합니다.

    다음: 사업단 검토

  2. 검토·보완 · 직원

    신청 대상·관련 사업·품목·금액·증빙을 확인합니다. 수량 추가·초과 품목 등은 승인된 작성 기준을 따릅니다.

    다음: 승인 또는 보완 요청

  3. 실제 집행 확인 · 직원

    실제 집행액과 증빙을 등록하고 신청액·승인액·실제 집행액을 구분합니다.

    다음: 관련 결과보고·마감

출장
  1. 제출 경로 확인 · 출장 신청자

    사업단 직원·산중교원은 원문상 기존 전자결재를 사용합니다. 그 외 대상은 지정 양식과 경로를 확인합니다.

    다음: 신청 제출

  2. 신청·검토 · 신청자·직원

    출장 목적·일정·장소·대상자와 관련 사업·증빙을 제출·검토합니다.

    다음: 결재·보완

  3. 처리 기록 · 직원

    기존 결재 상태와 필요한 증빙을 확인하고 해당 사업에 연결합니다.

    다음: 기존 절차에 따른 완료

야간 및 휴일 식대
  1. 업무일지 작성 · 학생TA·교수·직원 등 해당자

    실제 근무일시·업무내용·참여자·사용금액과 필요한 영수증을 준비합니다.

    다음: 사업단 검토

  2. 조건·증빙 확인 · 직원

    승인된 집행 시각·한도·지역 조건과 실제 근무·증빙을 확인합니다.

    다음: 승인 또는 보완 요청

  3. 집행·보관 · 직원

    실제 처리 결과를 사업별로 연결하고 최종본을 보관합니다.

    다음: 마감

장비 사용과 활용도
  1. 장비 사용 접수 · 학생·조교 등 장비 사용자

    실제 장비와 교과목·프로그램, 활용 목적·시작·종료 정보를 기록합니다.

    다음: 사용기록 확인

  2. 기록 확인 · 조교·직원

    장비 식별·시작종료 짝·겹친 시간과 활용 분류를 확인합니다. TA 활동시간을 장비 가동시간으로 그대로 복사하지 않습니다.

    다음: 기간별 집계

  3. 활용도 집계 · 직원

    승인된 분류 기준으로 A=B+D, 교육 활용률=B/A를 집계합니다. 지정 비교과 목록을 적용합니다.

    다음: 검토·보관

전문가 활용
  1. 신청 · 교수·지정 신청자

    활용 목적·일시·대상·시간과 관련 사업 정보를 제출합니다. 신분·계좌 자료는 승인된 별도 경로를 따릅니다.

    다음: 사업단 검토

  2. 기준·증빙 검토 · 직원

    내외부 구분·승인 단가·인정 시간과 활용 증빙을 확인합니다.

    다음: 직원 지급 처리

  3. 처리 결과 보관 · 직원

    지급 처리 결과와 관련 증빙을 해당 사업에 연결합니다.

    다음: 마감 또는 보완

원고료
  1. 원고·신청 제출 · 교수·해당 저자

    교보재명·저자·문서종류·매수와 원고 증빙을 제출합니다.

    다음: 사업단 검토

  2. 인정 매수·단가 검토 · 직원

    인정 매수와 단가를 확정하고 관련 증빙을 확인합니다.

    다음: 직원 지급 처리

  3. 처리 결과 보관 · 직원

    처리 결과·최종 원고·증빙을 연결하고 개정판을 구분합니다.

    다음: 마감 또는 보완

개인정보 동의
  1. 안내·서명 · 해당 신청자

    해당 신청에 필요한 승인된 동의 문구를 확인하고 요구된 서명을 합니다.

    다음: 제한된 제출 경로로 제출

  2. 수신·보관 확인 · 직원

    수신·서명·문구 버전을 확인하고 제한된 위치에 보관합니다.

    다음: 해당 신청과 연결

인턴일지
  1. 일지 작성·제출 · 학생

    학생용에 등록된 폼에서 해당 일지를 직접 작성·제출합니다.

    다음: 담당자 확인

  2. 확인 · 교수·지정 담당자

    교수용에 등록된 확인용 시트를 이용합니다. 세부 확인·보완 절차는 담당자 안내로 확정합니다.

    다음: 확인 또는 보완 안내
